# Prompt Generator Node for ComfyUI (Mistral)

Нода для **автоматической генерации промптов** для ComfyUI с использованием **Mistral LLM API**.
Позволяет преобразовывать произвольное пользовательское описание в структурированный, детализированный prompt, подходящий для SDXL и других пайплайнов генерации изображений.


## ✨ Возможности

* Генерация **positive prompt** на основе пользовательского запроса
* Поддержка разных **стилей промпта**:

  * `sdxl` — взвешенный SDXL-совместимый формат
  * `descriptive` — естественный описательный текст
* Управление **уровнем детализации**:

  * `minimal`
  * `normal`
  * `detailed`
  * `very detailed`
* Поддержка нескольких моделей **Mistral**
* Fallback-режим — при отсутствии API-ключа возвращается исходный текст
* Полная совместимость с ComfyUI node system


## 📁 Установка

### Размещение кода

Репозиторий с нодой должен быть размещён в директории пользовательских нод ComfyUI:

```text
ComfyUI/
└── custom_nodes/
    └── ai-producer/
        ├── __init__.py
        ├── prompt_generator.py
        └── .env
```

После этого нужно **перезапустить ComfyUI**.

---

### 🔐 Настройка Mistral API

#### Вариант 1 — через `.env` (рекомендуется)

Необходимо создать файл `.env` в корне ComfyUI:

```env
MISTRAL_API_KEY=your_api_key_here
```

Нода автоматически подхватит ключ через `python-dotenv`.

---

#### Вариант 2 — вручную в интерфейсе

В поле **API Key** в самой ноде можно указать ключ напрямую.

## 🧩 Параметры ноды

### Обязательные

| Параметр       | Описание                                                   |
| -------------- | ---------------------------------------------------------- |
| `user_request` | Исходное описание сцены                                    |
| `prompt_style` | `sdxl` или `descriptive`                                   |
| `detail_level` | Уровень детализации промпта                                |
| `api_base_url` | URL Mistral API (по умолчанию `https://api.mistral.ai/v1`) |
| `api_key`      | API-ключ Mistral                                           |
| `model`        | Модель Mistral                                             |

---

### Опциональные

| Параметр               | Описание                                                  |
| ---------------------- | --------------------------------------------------------- |
| `negative_prompt`      | Негативный промпт (если пусто — используется стандартный) |
| `custom_system_prompt` | Пользовательский system prompt (перекрывает стандартный)  |

---

## 📤 Выходы

Нода возвращает **два строковых значения**:

1. `positive_prompt` — сгенерированный позитивный промпт
2. `negative_prompt` — итоговый негативный промпт

Их можно напрямую подключать к:

* `CLIPTextEncode`
* `Conditioning`
* SDXL / Base Diffusion пайплайнам

---

## 🧠 Логика работы

1. Формируется system prompt в зависимости от:

   * выбранного стиля
   * уровня детализации
2. Отправляется запрос в Mistral Chat Completion API
3. Ответ очищается от:

   * markdown
   * кавычек
   * префиксов (`Prompt:`, `SDXL:` и т.п.)
4. Возвращается чистый prompt, готовый для генерации

Если API недоступен — нода **без ошибок** возвращает исходный текст пользователя.

---

## 🧪 Пример использования

**Ввод:**

```text
a beautiful landscape with mountains and lake
```

**Выход (SDXL):**

```text
(mountain landscape:1.6), (clear lake:1.4), snow-capped peaks, soft reflections, wide angle view, cinematic lighting, atmospheric depth, ultra detailed, high quality
```

---

## ⚠️ Примечания

* Нода **не выполняет генерацию изображений**, а только подготавливает промпты
* Не зависит от конкретного sampler или diffusion-модели
* Подходит для агентских и workflow-сценариев
* Можно использовать как frontend-слой над LLM
