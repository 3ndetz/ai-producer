# AI Producer

Welcome to **AI Producer** - an agent-based system for iterative image generation using LLM and VLM! The system automatically improves image quality through the cycle: Planner → Generator → Critic.

## How to Use 

1. Describe the desired image in the chat.
2. The system will analyze the request and plan the generation.
3. The Generator will create an image based on the plan.
4. The Critic will evaluate the result and suggest improvements.
5. Iterations will repeat until the perfect result is achieved!
